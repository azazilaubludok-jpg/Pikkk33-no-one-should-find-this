# Стенка

Анонимная стена: любой пишет пост (можно с ником), и он сразу появляется у всех, кто открыл сайт.

- Сайт — один файл `index.html`, без сборки.
- Посты хранятся в Supabase (бесплатный тариф).
- Защита: пост до 500 символов, ник до 32, не больше 30 постов в минуту на всю стену, пауза 15 секунд между постами у одного человека, ловушка для ботов.
- Менять и удалять посты может только владелец через панель Supabase.

## Как запустить (≈10 минут)

1. **Supabase.** Зарегистрируйся на supabase.com → New project (регион любой, пароль базы запомни).
2. **База.** В проекте открой **SQL Editor → New query**, вставь всё из `supabase/schema.sql`, нажми **Run**.
3. **Ключи.** **Project Settings → API**: скопируй **Project URL** и **anon public** ключ в `config.js`.
   Ключ `service_role` никуда не вставляй — он секретный.
4. **Публикация.** На GitHub: **Settings → Pages → Deploy from a branch**, выбери ветку и папку `/ (root)`.
   Через минуту сайт будет по адресу `https://<логин>.github.io/<репозиторий>/`.

Проверить локально можно и без GitHub: открой `index.html` в браузере.

## Модерация

Удалить пост: Supabase → **Table Editor → posts** → выдели строку → Delete.
Новые посты у всех появятся сами, удалённые исчезнут после обновления страницы.
