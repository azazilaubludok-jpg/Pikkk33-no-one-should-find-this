# Стенка

**Анонимная стена: пиши что хочешь, и это увидят все.**

👉 **[Открыть Стенку](https://azazilaubludok-jpg.github.io/Pikkk33-no-one-should-find-this/)**

- Регистрироваться не нужно: открыл, написал, готово.
- Новые посты появляются у всех сразу, страницу обновлять не надо.
- Ник по желанию, по умолчанию ты «аноним».
- Пост до 500 символов. Ctrl+Enter отправляет.

### Правила

Посты видят все, кто открыл сайт, и удалить свой пост сам ты не сможешь. Не пиши личные данные: свои и чужие телефоны, адреса, пароли. Спам и мерзость удаляются.

## Как это устроено

| Файл | Что внутри |
|---|---|
| `index.html` | Весь сайт: вёрстка, стили и логика в одном файле, без сборки |
| `config.js` | Адрес базы и публичный ключ |
| `supabase/schema.sql` | Таблица постов, правила доступа и защита от флуда |

Посты хранятся в [Supabase](https://supabase.com) (бесплатный тариф), сайт раздаёт GitHub Pages.

Защита от мусора:
- длина поста от 1 до 500 символов, ника до 32;
- на всю стену не больше 30 постов в минуту;
- пауза 15 секунд между постами одного человека;
- скрытое поле-ловушка для ботов.

Посетители могут только читать и добавлять посты. Менять и удалять их может только владелец, через панель Supabase.

## Своя копия

1. Создай проект на supabase.com.
2. Открой **SQL Editor → New query**, вставь содержимое `supabase/schema.sql` и нажми **Run**.
3. Скопируй **Project URL** и **Publishable key** (раньше он назывался **anon**) в `config.js`. Ключ `secret` / `service_role` никуда не вставляй.
4. Включи GitHub Pages: **Settings → Pages → Deploy from a branch**.

## Модерация

Supabase → **Table Editor → posts** → отметь строку → **Delete**.
